Ejercicio 5.2

Ejercicios de autoevaluación

5.2 Indique si cada uno de los siguientes enunciados es verdadero o falso. Si es falso, explique por qué:

a) La regla @font-face especifica que se utilizará una fuente incrustada cuando el documento se despliegue en una pantalla de computadora.
Falso. La regla @media screen especifica esto[cite: 16].

b) Podemos usar gradientes en cualquier propiedad que acepte una imagen.
Verdadero[cite: 16].

c) Un gradiente horizontal cambia en forma gradual de arriba hacia abajo.
Falso. Cambia de izquierda a derecha[cite: 16].

d) Podemos agregar líneas entre columnas mediante el uso de la propiedad column-gap.
Falso. Se usa la propiedad column-rule[cite: 16].

e) La regla @media determina el tipo y tamaño del dispositivo... Los estilos de la regla se aplican sólo si el resultado es falso.
Falso. Se aplican sólo si el resultado es verdadero[cite: 16].

f) Para agregar múltiples imágenes de fondo... usamos la propiedad background-position para especificar en dónde colocar cada imagen mediante el uso del modelo de cajas.
Falso. Se usa la propiedad background-origin[cite: 16].
