11.4 El método floor de Math puede usarse para redondear un número a un lugar decimal específico. Por ejemplo, la instrucción y = Math.floor( x * 10 + .5 ) / 10; redondea x a la posición de décimas (la primera posición a la derecha del punto decimal). La instrucción y = Math.floor( x * 100 + .5 ) / 100; redondea x a la posición de centésimas. Escriba una secuencia de comandos que defina cuatro funciones para redondear un número x de varias formas:

a) redondearAEntero( numero )
b) redondearADecimas( numero )
c) redondearACentesimas( numero )
d) redondearAMilesimas( numero )
