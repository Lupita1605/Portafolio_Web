Ejercicios de autoevaluación

9.5 Localice el error en cada uno de los siguientes segmentos de programa y explique cómo corregirlo:

a)

method g()
{
  document.writeln( "Dentro del m&eacute;todo g" );
}

Error: method no es la palabra clave para definir una función.
Corrección: Cambiar method por function.


b)

// Esta función debe devolver la suma de sus argumentos
function suma(x, y)
{
  var resultado;
  resultado = x + y;
}

Error: La función calcula la suma pero no devuelve el valor.
Corrección: Agregar la instrucción return resultado; al final de la función (o simplemente return x + y;).


c)

function f( a );
{
  document.writeln( a );
}

Error: Hay un punto y coma (;) después del paréntesis de los parámetros.
Corrección: Eliminar el punto y coma (;) después de function f( a ).
