Ejercicio del Capítulo 8

8.5 ¿Qué es lo que hace el siguiente programa?

<!DOCTYPE html<
<!--Ejercicio 8.5: ej08_05.html-->
<html>
  <head>
       <meta charset = "utf-8">
       <title>Misterio</title>
       <script>

           document.writeln("<table"> );

           for ( var i = 1; i <= 10; i++);
           {
               document.writeln("<tr>" );

               for ( var j = 1; j <= 5; j++)
                   document.writeln( "<td>(" + i + " . " + j + ")</td>);

                   document.writeln( "</tr>");
           } // fin de for

            document.write.ln("</table>" );
       </script>
  <head><body></body>
</html>

Respuesta: El programa genera una tabla HTML de 10 filas por 5 columnas. Cada celda contiene el número de fila y el número de columna en formato "i, j",
comenzando en 1, 1 y terminando en 10, 5.
