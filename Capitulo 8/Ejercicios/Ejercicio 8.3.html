Ejercicios de autoevaluación

8.3 Encuentre el error en cada uno de los siguientes
segmentos de código, y explique cómo corregirlo:

a)
x = 1;
while ( x <= 10 );
    ++x;
}

Error: El punto y coma después del encabezado while
provoca un ciclo infinito; además falta una llave izquierda.
Corrección: Reemplazar el punto y coma por una llave
izquierda ({), o eliminar tanto el punto y coma (;) como la llave derecha (}).

b)
switch ( n )
{
    case 1:
        document.writeln( "El número es 1" );
    case 2:
        document.writeln( "El número es 2" );
        break;
    default:
        document.writeln( "El número no es 1 ni 2" );
        break;
}

Error: Falta una instrucción break en las
instrucciones del primer case.
Corrección: Agregue una instrucción break al final
de las instrucciones para el primer case. Cabe mencionar que esta
omisión no es necesariamente un error, si desea que la instrucción del
case 2: se ejecute siempre que lo haga la instrucción del case 1:.

c) El siguiente código debe imprimir los valores 1 a 10:
n = 1;
while ( n < 10 )
    document.writeln( n++ );

Error: Se está utilizando un operador relacional inadecuado
en la condición de continuación de la instrucción de repetición while.
Corrección: Use <= en vez de <, o cambie el 10 a 11.
