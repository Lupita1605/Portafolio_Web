8.13 Dada la siguiente instrucción switch:

switch ( k )
{
  case 1:
    break;
  case 2:
  case 3:
    ++k;
    break;
  case 4:
    --k;
    break;
  default:
    k *= 3;
} //fin de switch

x = k;

¿Qué valores se asignan a x cuando k tiene valores de 1, 2, 3, 4 y 10?
