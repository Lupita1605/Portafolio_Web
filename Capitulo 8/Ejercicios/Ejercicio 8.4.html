Ejercicios

8.4 Encuentre el error en cada uno de los siguientes
segmentos de código. [Nota: puede haber más de un error].

a)
For ( x = 100, x >= 1, ++x )
 document.writeln( x );

Error: La palabra for debe ir en minúsculas.
Además, se usaron comas en vez de puntos y comas (;) dentro del for,
y se usó incremento (++x) en lugar de decremento (--x).

b) El siguiente código debe imprimirse sin importar
si el valor entero es par o impar:

switch ( valor % 2 )
{
 case 0:
 document.writeln( "Entero par" );
 case 1:
 document.writeln( "Entero impar" );
}

Error: Falta la instrucción break en el case 0.
Sin el break, cuando sea par también se ejecutará el case 1.

c) El siguiente código debe imprimir los enteros
impares del 19 al 1:

for ( x = 19; x >= 1; x += 2 )
 document.writeln( x );

Error: El contador está mal modificado, suma en lugar de restar.
Debe usarse x -= 2 para ir hacia atrás del 19 al 1.

d) El siguiente código debe imprimir los enteros
pares del 2 al 100:

contador = 2;
do {
 document.writeln( contador );
 contador += 2;
} while ( contador < 100 );

Error: Le falta el operador relacional <=.
Con < 100 solo imprime hasta el 98, debe ser contador <= 100.
