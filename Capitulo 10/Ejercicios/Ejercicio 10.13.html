Ejercicios

10.13 Etiquete los elementos del arreglo bidimensional de tres por cinco llamado ventas para indicar el orden en el que se deben establecer en cero mediante el siguiente segmento de programa:

for ( var fila in ventas )
{
   for ( var col in ventas[ fila ] )
   {
      ventas[ fila ][ col ] = 0;
   }
}

Respuesta:
Los elementos se procesan por filas, de izquierda a derecha (por columnas) en el siguiente orden numérico secuencial:

Fila 0:
1. ventas[ 0 ][ 0 ]
2. ventas[ 0 ][ 1 ]
3. ventas[ 0 ][ 2 ]
4. ventas[ 0 ][ 3 ]
5. ventas[ 0 ][ 4 ]

Fila 1:
6. ventas[ 1 ][ 0 ]
7. ventas[ 1 ][ 1 ]
8. ventas[ 1 ][ 2 ]
9. ventas[ 1 ][ 3 ]
10. ventas[ 1 ][ 4 ]

Fila 2:
11. ventas[ 2 ][ 0 ]
12. ventas[ 2 ][ 1 ]
13. ventas[ 2 ][ 2 ]
14. ventas[ 2 ][ 3 ]
15. ventas[ 2 ][ 4 ]
