Ejercicios de autoevaluación

10.5 Encuentre el o los errores en cada uno de los siguientes segmentos de programa y corríjalos:

a)

var b = new Array( 10 );
var longitud = b.length;

for ( var i = 0; i <= longitud; ++i )
{
   b[ i ] = 1;
}
Error: Se hace referencia al elemento de un arreglo fuera de los límites del arreglo (b[10]). (Nota: en realidad éste es un error lógico y no sintáctico).
Corrección:
for ( var i = 0; i < longitud; ++i )

b)
var a = [ [ 1, 2 ], [ 3, 4 ] ];
a[ 1, 1 ] = 5;
Error: El indexado de arreglos se realiza de manera incorrecta.
Corrección:
a[ 1 ][ 1 ] = 5;
