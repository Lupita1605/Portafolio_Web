10.9 Considere un arreglo de dos por tres que almacena enteros.

a) Escriba una instrucción para declarar y crear el arreglo t.

var t = [ [ 0, 0, 0 ], [ 0, 0, 0 ] ];

// O también:
var t = new Array( new Array( 3 ), new Array( 3 ) );
b) ¿Cuántas filas tiene t?
Respuesta: Tiene 2 filas.

c) ¿Cuántas columnas tiene t?
Respuesta: Tiene 3 columnas.

d) ¿Cuántos elementos tiene t?
Respuesta: Tiene 6 elementos (2 x 3).

e) Escriba los nombres de todos los elementos en la fila 1 de t.
Respuesta: t[ 1 ][ 0 ], t[ 1 ][ 1 ], t[ 1 ][ 2 ] (asumiendo la fila con índice 1).

f) Escriba los nombres de todos los elementos en la tercera columna de t.
Respuesta: t[ 0 ][ 2 ], t[ 1 ][ 2 ] (asumiendo el índice 2 para la tercera columna).

g) Escriba una sola instrucción para establecer el elemento de t en la fila 1 y la columna 2 en cero.
t[ 1 ][ 2 ] = 0;
h) Escriba una serie de instrucciones para inicializar cada elemento de t en cero.
t[ 0 ][ 0 ] = 0;
t[ 0 ][ 1 ] = 0;
t[ 0 ][ 2 ] = 0;
t[ 1 ][ 0 ] = 0;
t[ 1 ][ 1 ] = 0;
t[ 1 ][ 2 ] = 0;
i) Escriba una instrucción for anidada para inicializar cada elemento de t en cero.
for ( var i = 0; i < t.length; ++i )
{
   for ( var j = 0; j < t[ i ].length; ++j )
   {
      t[ i ][ j ] = 0;
   }
}
j) Escriba una serie de instrucciones para determinar e imprimir el valor más pequeño en el arreglo t.
var menor = t[ 0 ][ 0 ];

for ( var i = 0; i < t.length; ++i )
{
   for ( var j = 0; j < t[ i ].length; ++j )
   {
      if ( t[ i ][ j ] < menor )
      {
         menor = t[ i ][ j ];
      }
   }
}

document.writeln( "El valor más pequeño es: " + menor );
k) Escriba una instrucción sin repetición para mostrar los elementos de la primera fila de t.
document.writeln( t[ 0 ][ 0 ] + " " + t[ 0 ][ 1 ] + " " + t[ 0 ][ 2 ] );
l) Escriba una serie de instrucciones para imprimir el arreglo t en un formato tabular ordenado. Liste los índices de columnas como encabezados a lo largo de la parte superior y liste los índices de fila en la parte izquierda de cada fila.
var resultado = "<table border='1'><tr><th></th><th>0</th><th>1</th><th>2</th></tr>";

for ( var i = 0; i < t.length; ++i )
{
   resultado += "<tr><th>" + i + "</th>";
   for ( var j = 0; j < t[ i ].length; ++j )
   {
      resultado += "<td>" + t[ i ][ j ] + "</td>";
   }
   resultado += "</tr>";
}

resultado += "</table>";
document.writeln( resultado );
