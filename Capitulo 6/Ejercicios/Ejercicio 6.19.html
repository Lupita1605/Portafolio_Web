Ejercicios

6.19 Escriba una secuencia de comandos que obtenga del usuario el radio de un círculo y produzca texto de HTML5 que muestre el diámetro, la circunferencia y el área de ese círculo. Use el valor constante 3.14159 para π. Use las técnicas de GUI que se muestran en la figura 6.7. [Nota: también puede usar la constante predefinida Math.PI para el valor de π. Esta constante es más precisa que el valor 3.14159. El objeto Math está definido por JavaScript y provee muchas herramientas matemáticas comunes]. Use las siguientes fórmulas (r es el radio): diámetro = 2r, circunferencia = 2πr, área = πr2.
