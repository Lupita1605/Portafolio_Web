6.13 Dada y = ax3 + 7, ¿cuáles de las siguientes instrucciones de JavaScript son correctas para esta ecuación?

a) y = a * x * x * x + 7;
Respuesta: Correcta. Representa a · x3 + 7.

b) y = a * x * x * (x + 7);
Respuesta: Incorrecta. Equivale a ax2(x + 7).

c) y = (a * x) * x * (x + 7);
Respuesta: Incorrecta. Equivale a ax2(x + 7).

d) y = (a * x) * x * x + 7;
Respuesta: Correcta. Los paréntesis no alteran el resultado de la multiplicación.

e) y = a * (x * x * x) + 7;
Respuesta: Correcta. Calcula x3 primero y luego lo multiplica por a.

f) y = a * x * (x * x + 7);
Respuesta: Incorrecta. Equivale a ax(x2 + 7).
