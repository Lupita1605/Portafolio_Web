6.12 ¿Cuál de las siguientes instrucciones de JavaScript contiene variables cuyos valores se modifican?

a) p = i + j + k + 7;
Respuesta: Modifica la variable p (se le asigna el resultado del cálculo).

b) window.alert("variables cuyos valores se destruyen");
Respuesta: No modifica ninguna variable (solo muestra texto en pantalla).

c) window.alert("a = 5");
Respuesta: No modifica ninguna variable (muestra la cadena "a = 5").

d) cadenaVal = window.prompt("Escriba una cadena:");
Respuesta: Modifica la variable cadenaVal (almacena el texto introducido por el usuario).
