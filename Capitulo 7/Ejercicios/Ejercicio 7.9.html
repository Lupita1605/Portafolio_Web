Ejercicios

7.9 Identifique y corrija los errores en cada uno de los siguientes segmentos de código. [Nota: puede haber más de un error en cada fragmento; a menos que haya declaraciones presentes, suponga que todas las variables están declaradas e inicializadas correctamente].

a)

if ( edad >= 65 );
document.writeln( "Edad es mayor o igual que 65" );
else
document.writeln( "Edad es menor que 65" );

Error: El punto y coma después de la condición del if separa la instrucción del else.
Corrección: Quitar el punto y coma después de ( edad >= 65 ).

b)

var x = 1, total;
while ( x <= 10 )
{
total += x;
++x;
}

Error: La variable total no está inicializada en 0.
Corrección: Inicializar total en 0 (var x = 1, total = 0;).

c)

var x = 1;
var total = 0;
while ( x <= 100 )
total += x;
++x;

Error: Faltan las llaves del ciclo while, lo que provoca un ciclo infinito.
Corrección: Encerrar total += x; y ++x; entre llaves { }.

d)

var y = 5;
while ( y > 0 )
{
document.writeln( y );
++y;

Error: Falta la llave de cierre } y el incremento ++y provoca un ciclo infinito.
Corrección: Cambiar ++y por --y; y agregar la llave de cierre } al final.
